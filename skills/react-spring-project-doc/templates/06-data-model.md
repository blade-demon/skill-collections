# Phase 6 — Data Model Analysis 模板

> 落盘到 `docs/.analysis/06-data-model-draft.md`。
> 输入：`03`（模型清单）/`04`（接口）/`05`（链路涉及模型）。逐个分析**核心** Entity/DTO/VO/Request/Response/Enum。
> 不必覆盖所有 POJO；优先覆盖出现在核心链路与核心接口里的模型。每个模型追加一条证据账本（类型：数据模型）。
> 字段含义无注释/无法确认的，标「待确认」，不要凭字段名编造业务语义。
>
> **证据优先级（表结构/字段/枚举）**：数据库迁移 DDL（Flyway `V*__*.sql` / Liquibase changelog）> JPA `@Table`/`@Column` 注解 / MyBatis resultMap > 仅凭字段名推断。
> 有迁移文件时，**以迁移 DDL 为表名、列名、类型、非空、默认值的最强证据**；迁移与 Entity 注解冲突时以迁移为准，并在「待确认项」记下差异。无迁移文件才退回注解/XML 推断，并相应**降一档置信度**。
