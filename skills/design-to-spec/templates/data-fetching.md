## 缓存与复用策略

- **缓存策略**：不缓存（每次挂载重新请求）/ 内存缓存 TTL = <N> 秒 / SWR（展示旧数据同时后台刷新）/ ⚠️ 待确认
- **缓存粒度**：按 `<参数组合>` 作为 key / 全局单例 / ⚠️ 待确认
- **失效触发**：用户主动刷新 / 超过 TTL / 外部事件（如提交成功后使缓存失效）
- **`stale` 态处理**：展示旧数据时是否有视觉标识（灰化 / 角标 / 不标注）

## 错误分级与降级策略

> 按错误来源和严重程度分级，每级定义独立的 UI 行为。

| 错误类型                 | 触发条件                                               | UI 表现                                              | 是否可重试          | 备注                        |
| ------------------------ | ------------------------------------------------------ | ---------------------------------------------------- | ------------------- | --------------------------- |
| 网络超时 / 断网          | 请求未在 `<N>` 秒内响应 / `navigator.onLine === false` | <离线提示组件 / toast>                               | 是，手动重试        |                             |
| 服务端错误（5xx）        | HTTP 状态码 ≥ 500                                      | <全屏错误页 / 组件内错误兜底>                        | 是，最多重试 <N> 次 | ⚠️ 待确认：重试间隔         |
| 业务错误（4xx）          | `error.code` 具体枚举值                                | <按 code 分支：403 → 引导登录，404 → 内容不存在提示> | 否                  | 枚举值见接口文档            |
| 数据为空（2xx 但无内容） | `data.items.length === 0` 或 `data === null`           | `empty` 态（见状态枚举）                             | —                   | 不属于错误，属于正常态      |
| 字段缺失 / 类型不符      | 前端 runtime 校验失败                                  | <降级展示（`partial` 态）/ 上报 Sentry>              | —                   | ⚠️ 待确认：是否需要前端校验 |

- **处理方案**：

## 状态机

> 列出组件所有可能的数据请求状态及其合法转换路径。与 `notes.md` 状态枚举对应，但这里专注于**请求生命周期**，不含纯 UI 状态（如 `isExpanded`）。

```
idle
  → loading（触发请求）
      → success（请求成功且数据合法）
      → empty（请求成功但数据为空）
      → error（请求失败 / 数据校验失败）
          → loading（用户点击重试）
      → fetchingMore（已有数据，追加下一页）[仅分页场景]
          → success（追加完成）
          → error（追加失败，保留已有数据）
```

**状态说明**：

| 状态           | 持久化     | 可并发               | 备注                         |
| -------------- | ---------- | -------------------- | ---------------------------- |
| `idle`         | —          | —                    | 初始态，未触发任何请求       |
| `loading`      | 否         | 否（新请求取消旧的） | ⚠️ 待确认：是否需要骨架屏    |
| `success`      | 视缓存策略 | —                    |                              |
| `empty`        | 视缓存策略 | —                    | 不显示 loading，直接展示空态 |
| `error`        | 否         | —                    | 保留上一次成功数据（若有）   |
| `fetchingMore` | —          | 否                   | 仅分页场景，已有列表保持可见 |
